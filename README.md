# 缓一缓 · 家庭冲突急救箱

按《家庭矛盾工具-产品方案.md》实现的 v1，六个引擎全部可用，PWA 离线。

## 怎么打开

**线上地址（已部署）：** https://guxi-commits.github.io/family-tool/

**方式一：手机浏览器直接访问**
打开上面网址即可用，什么都不用装。

**方式二：装到手机上（推荐）**

1. 用手机浏览器打开上面网址
2. iOS Safari：点分享 → 「添加到主屏幕」
3. Android Chrome：菜单 → 「安装应用」

装完就是一个独立图标，断网也能用。

**更新方式：** 改完代码后在 `app/` 目录 `git add -A && git commit -m "..." && git push`，Pages 会自动重新构建（约 1 分钟）。手机端下次打开时刷新即生效（Service Worker 会在后台更新缓存）。

**本地起服务测试：**

```bash
cd family-tool/app
python -m http.server 8080
```

然后手机和电脑连同一个 WiFi，访问 `http://电脑IP:8080`。

## 六个引擎

| tab | 名字 | 什么时候用 | 输出 |
|---|---|---|---|
| 现在 | 分流 | 刚打开时 | 三问决定去哪个模块 |
| 停 | 降温室 | 情绪 ≥ 7 分 | 情绪命名 + 生理性叹息 + 20 分钟倒计时 |
| 说 | 需求解码 | 有话说不出口 | 改写版 + 四骑士检测 + 四层拆解 |
| 看 | 循环地图 | 同一个架吵过很多次 | 环形图 + 「你能改哪一格」 |
| 我 → 约 | 谈规则 | 反复为「谁能管什么」吵 | 三档边界表 + DEAR MAN 四步 |
| 我 → 补 | 修复对话 | 吵完冷战中 | 分级修复句 + 四步复盘 |

另外「现在」页有日常维护：6 秒动作、记录联结邀请、连续存款天数。

## 几个设计细节

- **入口不分关系，分状态。** 首页问的是「你在气头上 / 有话说不出口 / 吵过很多次」，不是「你要处理夫妻还是婆媳」。同一场冲突，三种状态对应三个不同模块。
- **「停」用生理性叹息，不用 4-7-8。** 双吸气 + 长呼，直接增加迷走神经张力，起效比数拍子快。
- **「看」的环形图只让你改自己那一格。** 其他四格的建议都比你的那格弱——因为那才是唯一有出口的地方。
- **改写不追求「说得漂亮」，追求不产生新的问题。** 每条规则都测过否定语义（「你根本不在乎」不能变成「你在乎」）。
- **含「离婚」这类句子的处理方式是改不动就不改。** 直接告诉你：这句话说出去要花很久才能收回。

## 数据

- 存在浏览器 localStorage，key `huanyihuan-v2`
- 不上传、不需要账号、没有后端
- 换手机、清缓存、无痕模式都会丢，重要的用「我 → 导出备份」
- 最多保留 400 条记录，超出自动丢最旧的
